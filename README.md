# One Sentence for a Traveler from 1800

A single sentence that explains the modern internet to someone arriving from the year 1800, using only words that existed before 1800. One comparison carries it all: the internet as a road of light, where the letters, books, and songs of the world fly to a small glass box in your pocket faster than ink dries — built from what a person from 1800 already knows (a road, a post office, a library), with no word coined after their time.

## Run it

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The output is deterministic: the same single sentence on every run.
